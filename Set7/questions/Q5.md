# Set 07 - Question 5: Trail Elevation Search

**Difficulty:** Medium (26 marks)

## Scenario
A hiking app records the altitude (in metres) at consecutive checkpoints along a trail that climbs strictly to a single summit and then descends strictly. Hikers ask 'at which checkpoint do I first reach altitude h?'. Because a checkpoint is read from a slow sensor log, the app wants to examine as few checkpoints as possible.

## Problem Statement
The array is a mountain: strictly increasing up to a unique peak, then strictly decreasing (n ≥ 3, the peak is neither the first nor the last element). Given a target h, print the smallest index whose value is h, or -1 if h does not occur. Do it in O(log n): find the peak by binary search, then binary-search the increasing part, and only if needed the decreasing part.

## Input Format
- Line 1: integer n.
- Line 2: n integers forming a mountain.
- Line 3: integer h.

## Output Format
- Print one integer: the smallest index with value h, or -1.

## Constraints
- 3 ≤ n ≤ 10^5
- -10^9 ≤ altitude, h ≤ 10^9
- Strictly increasing then strictly decreasing, with the peak strictly inside

## Sample Input
```
9
2 5 9 14 20 17 11 6 1
11
```

## Sample Output
```
6
```
