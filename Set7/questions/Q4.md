# Set 07 - Question 4: Transaction Time Window

**Difficulty:** Medium (26 marks)

## Scenario
A payment system stores transaction amounts of one merchant in sorted order (many transactions share the same amount, for example fixed-price tickets). An auditor wants to know where the block of transactions with a given amount starts and ends in the sorted list, to inspect that block.

## Problem Statement
Given a non-decreasing array of n amounts and a target x, print the 0-based index of the first occurrence of x and the index of the last occurrence, separated by a space. If x does not occur, print -1 -1. Use two binary searches; do not scan linearly and do not use bisect.

## Input Format
- Line 1: integer n.
- Line 2: n integers in non-decreasing order.
- Line 3: integer x.

## Output Format
- Print two integers: first index and last index, or -1 -1.

## Constraints
- 1 ≤ n ≤ 10^5
- -10^9 ≤ amount, x ≤ 10^9
- The array may contain duplicates

## Sample Input
```
10
5 7 7 8 8 8 8 10 12 12
8
```

## Sample Output
```
3 6
```
