# Set 08 - Question 4: Rotated Log Lookup

**Difficulty:** Medium (26 marks)

## Scenario
A logging service stores sequence numbers in a circular buffer. Logically the numbers are sorted, but the buffer's start pointer has moved, so physically the array is a sorted array rotated by an unknown offset. Support engineers need to find the physical position of a given sequence number quickly.

## Problem Statement
Given a rotated sorted array of n distinct integers and a target t, print the index of t, or -1 if t is absent, in O(log n) time. Do not first locate the rotation point with a linear scan and do not use built-in search methods.

## Input Format
- Line 1: integer n.
- Line 2: n distinct integers forming a rotated sorted array.
- Line 3: integer t.

## Output Format
- Print one integer: the index of t, or -1.

## Constraints
- 1 ≤ n ≤ 10^5
- -10^9 ≤ value, t ≤ 10^9
- All values are distinct

## Sample Input
```
8
15 18 22 31 3 6 9 12
9
```

## Sample Output
```
6
```
