# Set 08 - Question 3: Earliest Slot After Shift Change

**Difficulty:** Easy (16 marks)

## Scenario
A hospital stores the start times (in minutes from midnight, all different) of appointment slots in increasing order, but after a shift change the rota was rotated: the list now starts in the middle of the original order and wraps around. The scheduler needs the earliest slot time, which is the minimum of the list.

## Problem Statement
The array is a sorted array of distinct integers that has been rotated by some unknown amount (possibly zero). Print the minimum element in O(log n) time using binary search; do not use min() or a full scan.

## Input Format
- Line 1: integer n.
- Line 2: n distinct integers forming a rotated sorted array.

## Output Format
- Print one integer: the minimum value.

## Constraints
- 1 ≤ n ≤ 10^5
- -10^9 ≤ value ≤ 10^9
- All values are distinct

## Sample Input
```
7
40 50 60 70 10 20 30
```

## Sample Output
```
10
```
