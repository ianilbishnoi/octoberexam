# Set 08 - Question 1: Square Tile Floor Planner

**Difficulty:** Easy (16 marks)

## Scenario
A contractor has x identical square floor tiles and wants to lay them as one large square block of s × s tiles. She wants the largest whole-number side s such that s × s tiles are available. The number of tiles can be astronomically large for industrial floors, so trying every side length one by one is too slow.

## Problem Statement
Given a non-negative integer x, print the largest integer s such that s × s ≤ x (the floor of the square root of x). Do not use the sqrt function, math.isqrt or the ** 0.5 trick; use binary search over the possible values of s.

## Input Format
- A single line containing the integer x.

## Output Format
- Print one integer s.

## Constraints
- 0 ≤ x ≤ 10^18

## Sample Input
```
99
```

## Sample Output
```
9
```
