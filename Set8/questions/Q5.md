# Set 08 - Question 5: Cargo Shipping Capacity

**Difficulty:** Medium (26 marks)

## Scenario
A freight company must ship n packages waiting in a fixed order at a depot. Each day the ship loads packages in that order (no reordering), up to its weight capacity, and sails. All packages must be delivered within D days. The company wants to charter the smallest possible ship capacity that makes this feasible.

## Problem Statement
Given the package weights in shipping order and D, print the minimum ship capacity C such that the packages can be shipped in order, each day carrying a consecutive group of packages whose total weight does not exceed C, using at most D days. The capacity must be at least the weight of the heaviest package.

## Input Format
- Line 1: integers n and D.
- Line 2: n integers, the weights in shipping order.

## Output Format
- Print one integer: the minimum capacity.

## Constraints
- 1 ≤ D ≤ n ≤ 5 × 10^4
- 1 ≤ weight ≤ 500
- Do not use built-in max() or sum()

## Sample Input
```
7 3
4 2 7 1 8 3 5
```

## Sample Output
```
13
```
