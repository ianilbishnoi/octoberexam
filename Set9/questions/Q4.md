# Set 09 - Question 4: Booking Overlap Consolidation

**Difficulty:** Medium (26 marks)

## Scenario
A conference-room system receives n booking requests, each a closed time interval [start, end] in whole minutes, in arbitrary order. Overlapping bookings (and bookings that share an endpoint) are to be consolidated into single blocks so that facilities staff can see the busy periods of the room.

## Problem Statement
Merge all intervals that overlap or touch (two closed intervals merge when they share at least one point, e.g. [1,4] and [4,5] merge into [1,5], whereas [1,4] and [5,6] do not). Print the resulting disjoint intervals in increasing order of start, one interval per line as 'start end'. Use your own sort; built-in sort functions are not allowed.

## Input Format
- Line 1: integer n.
- Next n lines: two integers start and end (start ≤ end).

## Output Format
- Print one merged interval per line as 'start end', ordered by start.

## Constraints
- 1 ≤ n ≤ 10^5
- 0 ≤ start ≤ end ≤ 10^9

## Sample Input
```
6
8 10
1 3
2 6
15 18
17 20
6 7
```

## Sample Output
```
1 7
8 10
15 20
```
