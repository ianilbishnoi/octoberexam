# Set 09 - Question 2: Judges' Trimmed Mean

**Difficulty:** Easy (16 marks)

## Scenario
In a talent contest n judges give integer scores. To reduce bias, the organisers discard the t lowest and the t highest scores and report the average of the remaining n − 2t scores, rounded to two decimals.

## Problem Statement
Given the n scores and an integer t with n − 2t ≥ 1, discard the t smallest and the t largest scores (equal scores are interchangeable) and print the arithmetic mean of the remaining scores formatted with exactly two digits after the decimal point. Implement your own sorting routine; built-in sort functions are not allowed.

## Input Format
- Line 1: integers n and t.
- Line 2: n integers, the scores.

## Output Format
- Print the trimmed mean with exactly two decimals (use the format '%.2f').

## Constraints
- 1 ≤ n ≤ 10^5
- 0 ≤ t and n − 2t ≥ 1
- 0 ≤ score ≤ 100

## Sample Input
```
10 1
8 9 7 10 6 9 5 8 9 10
```

## Sample Output
```
8.25
```
