# Set 04 - Question 5: Longest Unique Scan Run

**Difficulty:** Medium (26 marks)

## Scenario
A conveyor belt scanner reads an item code for every parcel passing by. Quality control wants the longest stretch of consecutive parcels in which no code appears twice, because such stretches can be audited as 'clean' batches.

## Problem Statement
Given the sequence of n scanned item codes, print the length of the longest contiguous segment in which all codes are different.

## Input Format
- Line 1: integer n.
- Line 2: n space-separated integers, the item codes.

## Output Format
- Print one integer: the length of the longest segment with no repeated code.

## Constraints
- 1 ≤ n ≤ 10^5
- 1 ≤ code ≤ 10^9

## Sample Input
```
10
12 7 9 4 5 3 12 6 8 2
```

## Sample Output
```
9
```
