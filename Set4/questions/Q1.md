# Set 04 - Question 1: Peak Traffic Window

**Difficulty:** Easy (16 marks)

## Scenario
A news website records the number of visitors for each of n consecutive hours. The operations team wants to schedule server upgrades away from the busiest period, defined as the k consecutive hours with the highest total visitors.

## Problem Statement
Given the hourly visitor counts and the window length k, print the largest possible total visitors over any k consecutive hours. Do not use built-in sum(), max() or slicing inside the loop; maintain the window total incrementally.

## Input Format
- Line 1: integers n and k.
- Line 2: n space-separated integers, the hourly visitor counts.

## Output Format
- Print one integer: the maximum window total.

## Constraints
- 1 ≤ k ≤ n ≤ 10^5
- -10^4 ≤ count ≤ 10^4 (negative values represent corrections)

## Sample Input
```
9 3
4 2 10 1 3 9 6 5 7
```

## Sample Output
```
20
```
