# Set 04 - Question 4: Plagiarism Pattern Scanner

**Difficulty:** Medium (26 marks)

## Scenario
A plagiarism checker looks for 'scrambled copies' of a short keyword inside a long document: a stretch of text that uses exactly the same letters as the keyword, in any order. It needs the starting position of every such stretch.

## Problem Statement
Given a text s and a keyword p (both lowercase English letters), print every index i (0-based, increasing) such that the substring s[i .. i+|p|−1] is an anagram of p, i.e. has the same multiset of letters. Print the word None if there is no such index. Overlapping occurrences are all reported.

## Input Format
- Line 1: the string s.
- Line 2: the string p.

## Output Format
- One line with the indices separated by single spaces, or None.

## Constraints
- 1 ≤ |s|, |p| ≤ 10^5
- Only lowercase letters a–z
- Counter, sorted() and slicing in the loop are not allowed

## Sample Input
```
cbaebabacd
abc
```

## Sample Output
```
0 6
```
