# Set 04 - Question 3: Strong Average Days

**Difficulty:** Easy (16 marks)

## Scenario
A school records the number of students present each day for n days. A 'strong period' is any k consecutive days whose average attendance is at least T. The principal wants to know how many strong periods (windows) exist.

## Problem Statement
Given n daily attendance counts, an integer k and a threshold T, print the number of windows of exactly k consecutive days whose average is at least T. To avoid fractions, a window qualifies when its sum is at least k·T. Overlapping windows are all counted.

## Input Format
- Line 1: integers n, k and T.
- Line 2: n space-separated integers, the daily counts.

## Output Format
- Print one integer: the number of qualifying windows.

## Constraints
- 1 ≤ k ≤ n ≤ 10^5
- 0 ≤ count ≤ 10^4
- 1 ≤ T ≤ 10^4

## Sample Input
```
8 3 4
2 2 2 2 5 5 5 8
```

## Sample Output
```
3
```
