# Set 03 - Question 3: Out-of-Stock Items to the End

**Difficulty:** Easy (16 marks)

## Scenario
A warehouse dashboard shows the stock count of n products in catalogue order. Products with count 0 are out of stock and should be pushed to the end of the list so that available products appear first, but the relative order of the available products must stay exactly as in the catalogue. The dashboard runs on a small device, so the rearrangement should happen inside the same array.

## Problem Statement
Given n stock counts, move every 0 to the end while keeping the relative order of the non-zero counts. Print the rearranged counts. Try to do it in a single pass without creating a second array.

## Input Format
- Line 1: integer n.
- Line 2: n space-separated integers, the stock counts.

## Output Format
- Print the rearranged counts on one line separated by spaces.

## Constraints
- 1 ≤ n ≤ 10^5
- 0 ≤ count ≤ 10^9

## Sample Input
```
9
0 14 0 3 7 0 0 9 5
```

## Sample Output
```
14 3 7 9 5 0 0 0 0
```
