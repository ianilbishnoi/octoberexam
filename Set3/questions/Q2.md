# Set 03 - Question 2: Voice Assistant Vowel Swap

**Difficulty:** Easy (16 marks)

## Scenario
A speech-to-text test tool deliberately garbles a phrase to test a spelling-correction feature: it keeps every consonant and space where it is, but reverses the order in which the vowels appear along the phrase.

## Problem Statement
Given a phrase made of English letters and single spaces, reverse the order of its vowels (a, e, i, o, u in either case) while all other characters stay in their original positions. Print the resulting phrase. Vowel letters keep their own case; only their positions change.

## Input Format
- A single line containing the phrase (letters and spaces; no leading or trailing spaces).

## Output Format
- Print the transformed phrase on one line.

## Constraints
- 1 ≤ length ≤ 2 × 10^5
- Characters are English letters or spaces

## Sample Input
```
Campus Library
```

## Sample Output
```
Campis Lubrary
```
