# Set 03 - Question 5: Seat Booking Cleanup

**Difficulty:** Medium (26 marks)

## Scenario
A theatre's booking table lists seat IDs in sorted order, one entry per booking. A seat may legally be booked at most twice (for the matinee and the evening show), but a software bug created extra duplicate entries. The cleanup tool must keep at most two entries per seat, preserve the order, and compact the table in place.

## Problem Statement
Given a sorted (non-decreasing) array of n seat IDs, remove extra duplicates in place so that every distinct value appears at most twice, keeping the first two occurrences. Print k, the length of the cleaned list, and then the first k values of the modified array.

## Input Format
- Line 1: integer n.
- Line 2: n space-separated integers in non-decreasing order.

## Output Format
- Line 1: the integer k.
- Line 2: the k remaining values separated by spaces.

## Constraints
- 1 ≤ n ≤ 10^5
- 1 ≤ seat ID ≤ 10^9
- The array is sorted; no extra array may be created for the final answer

## Sample Input
```
10
1 1 1 2 2 3 3 3 3 4
```

## Sample Output
```
7
1 1 2 2 3 3 4
```
