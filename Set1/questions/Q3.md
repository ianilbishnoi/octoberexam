# Set 01 - Question 3: Second Highest Sensor Reading

**Difficulty:** Easy (16 marks)

## Scenario
A weather station records n temperature readings in one day. The station manager wants the second-highest distinct reading, to compare against the day's peak and judge how sharp the peak was.

## Problem Statement
Given n integer readings (possibly negative and possibly repeated), print the second-largest distinct value. Distinct means equal values count once: for the readings 9 9 5 the second-largest distinct value is 5. If fewer than two distinct values exist, print the word None.

## Input Format
- Line 1: integer n.
- Line 2: n space-separated integers, the readings.

## Output Format
- Print one integer: the second-largest distinct reading, or the word None if it does not exist.

## Constraints
- 1 ≤ n ≤ 10^5
- -10^9 ≤ reading ≤ 10^9
- Do not use built-in max, min, sum or sorting.

## Sample Input
```
9
31 28 35 35 29 -4 35 28 30
```

## Sample Output
```
31
```
