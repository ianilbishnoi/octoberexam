# Set 01 - Question 1: Gift Card Pairing at Checkout

**Difficulty:** Easy (16 marks)

## Scenario
An online store lets customers pay with a gift card whose balance must be used up exactly. At checkout, the system must find two different items in the customer's cart whose prices add up to exactly the gift-card balance.

## Problem Statement
Given the prices of the n items in a cart (in the order they were added) and the gift-card balance T, find two different positions i and j (0-based, i < j) such that price[i] + price[j] = T. The input guarantees that exactly one such pair of positions exists. The same position cannot be used twice.

## Input Format
- Line 1: integer n, the number of items.
- Line 2: n space-separated integers, the item prices.
- Line 3: integer T, the gift-card balance.

## Output Format
- Print two space-separated integers i and j (0-based, i < j) on one line.

## Constraints
- 2 ≤ n ≤ 10^5
- 1 ≤ price[i] ≤ 10^9
- 1 ≤ T ≤ 2 × 10^9
- Exactly one pair of positions (i, j) satisfies the condition

## Sample Input
```
6
120 45 80 200 35 150
235
```

## Sample Output
```
3 4
```
