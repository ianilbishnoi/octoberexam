# Set 02 - Question 5: Delivery Route Rotation

**Difficulty:** Medium (26 marks)

## Scenario
A courier company schedules n delivery stops for a driver. To balance workload, each new day's route is the previous day's route rotated to the right by k stops: the last k stops move to the front, and all other stops shift right keeping their order. Memory on the driver's handheld device is tiny, so the rotation must be done inside the same array without allocating another full-size list.

## Problem Statement
Given the route (stop IDs in order) and the integer k, print the route after rotating it to the right by k positions. The value k may be 0, equal to n or larger than n; rotating by n returns the original order. Slicing tricks such as a[k:] + a[:k] and list reversal helpers are not allowed; reverse with explicit loops and swaps.

## Input Format
- Line 1: two integers n and k.
- Line 2: n space-separated integers, the stop IDs.

## Output Format
- Print the rotated route as n space-separated integers on one line.

## Constraints
- 1 ≤ n ≤ 10^5
- 0 ≤ k ≤ 10^9
- 1 ≤ stop ID ≤ 10^9

## Sample Input
```
7 3
1 2 3 4 5 6 7
```

## Sample Output
```
5 6 7 1 2 3 4
```
