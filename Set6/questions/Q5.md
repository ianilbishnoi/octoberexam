# Set 06 - Question 5: Sensor Readings with Heavy Duplicates

**Difficulty:** Medium (26 marks)

## Scenario
A factory sensor reports a quantised reading (a small integer level) every second, so a day's data contains many repeated values and only a few distinct ones. Analysts want the readings sorted in ascending order. A sort that treats equal readings badly would waste time on the duplicates, so the team wants a quicksort that groups all readings equal to the pivot together in one step.

## Problem Statement
Sort the n readings in non-decreasing order using quicksort with 3-way (Dutch-flag) partitioning: elements smaller than the pivot, equal to the pivot and larger than the pivot are separated, and only the smaller and larger parts are sorted further. Use an explicit stack of index ranges (no recursion) and choose the middle element of each range as pivot. Built-in sorting is not allowed.

## Input Format
- Line 1: integer n.
- Line 2: n space-separated integers, the readings.

## Output Format
- Print the sorted readings on one line separated by spaces.

## Constraints
- 1 ≤ n ≤ 10^5
- 0 ≤ reading ≤ 10^9 (typically only a few distinct values)

## Sample Input
```
10
3 1 3 2 3 1 2 3 1 3
```

## Sample Output
```
1 1 1 2 2 3 3 3 3 3
```
