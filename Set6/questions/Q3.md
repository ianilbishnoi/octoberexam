# Set 06 - Question 3: Combined Attendee List

**Difficulty:** Easy (16 marks)

## Scenario
Two student clubs each keep a sorted list of the student IDs who registered for their own workshop (no ID repeated within one list). The organisers want one combined invitation list in ascending order where a student who registered in both clubs appears only once.

## Problem Statement
Given two strictly increasing lists A (m IDs) and B (n IDs), print the union of the two lists in strictly increasing order, with each ID printed once. If both lists are empty, print an empty line (this does not occur in the tests). Built-in sorting is not allowed; exploit the fact that both inputs are already sorted.

## Input Format
- Line 1: integers m and n.
- Line 2: m space-separated integers (list A; empty line if m = 0).
- Line 3: n space-separated integers (list B; empty line if n = 0).

## Output Format
- Print the merged distinct IDs on one line separated by spaces.

## Constraints
- 0 ≤ m, n ≤ 10^5, m + n ≥ 1
- 1 ≤ ID ≤ 10^9
- Each input list is strictly increasing

## Sample Input
```
5 4
3 8 12 20 25
5 8 20 31
```

## Sample Output
```
3 5 8 12 20 25 31
```
