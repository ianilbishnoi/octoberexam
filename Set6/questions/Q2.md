# Set 06 - Question 2: Warehouse Bin Sorting

**Difficulty:** Easy (16 marks)

## Scenario
A conveyor delivers parcels tagged 0 (fragile), 1 (standard) or 2 (heavy). Before loading, the parcels must be arranged so that all fragile ones come first, then standard, then heavy. The loading arm can only swap two parcels at a time and has no room for a second copy of the belt.

## Problem Statement
Given n tags, each 0, 1 or 2, rearrange them in place into non-decreasing order and print the result. Aim for a single left-to-right pass using three pointers, without a general-purpose sort.

## Input Format
- Line 1: integer n.
- Line 2: n space-separated tags, each 0, 1 or 2.

## Output Format
- Print the rearranged tags on one line separated by spaces.

## Constraints
- 1 ≤ n ≤ 10^5
- Each tag is 0, 1 or 2

## Sample Input
```
8
2 0 1 2 1 0 1 0
```

## Sample Output
```
0 0 0 1 1 1 2 2
```
