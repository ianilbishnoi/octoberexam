# Set 10 - Question 2: Price Tier Floor and Ceiling

**Difficulty:** Easy (16 marks)

## Scenario
A shop's price list contains the available price tiers in increasing order (the same tier may be listed more than once). A customer states a budget q. The shop wants to quote the most expensive tier not above the budget (floor) and the cheapest tier not below the budget (ceiling), so that it can suggest the nearest options on either side.

## Problem Statement
Given a non-decreasing array of n prices and a query value q, print two values separated by a space: the floor (largest price ≤ q) and the ceiling (smallest price ≥ q). If a value does not exist print the word None in its place. Use binary search.

## Input Format
- Line 1: integer n.
- Line 2: n integers in non-decreasing order.
- Line 3: integer q.

## Output Format
- Print 'floor ceiling' where each is an integer or None.

## Constraints
- 1 ≤ n ≤ 10^5
- -10^9 ≤ price, q ≤ 10^9

## Sample Input
```
6
10 20 30 40 50 60
35
```

## Sample Output
```
30 40
```
