# Set 10 - Question 1: Sensor Deviation Magnitudes

**Difficulty:** Easy (16 marks)

## Scenario
A calibration sensor reports deviations from a reference value, stored in increasing order, so negative deviations come first. Quality engineers need the squared deviations in increasing order as well, to see the smallest error magnitudes first.

## Problem Statement
Given a non-decreasing array of n integers (possibly negative), print the squares of its elements in non-decreasing order. Squaring and then calling a built-in sort is not allowed; exploit the fact that the input is already sorted.

## Input Format
- Line 1: integer n.
- Line 2: n integers in non-decreasing order.

## Output Format
- Print n integers: the squares in non-decreasing order, separated by spaces.

## Constraints
- 1 ≤ n ≤ 10^5
- -10^4 ≤ value ≤ 10^4

## Sample Input
```
7
-9 -4 -2 0 3 5 8
```

## Sample Output
```
0 4 9 16 25 64 81
```
