# Set 10 - Question 3: One-Trade Stock Profit

**Difficulty:** Easy (16 marks)

## Scenario
A trader has the closing price of a stock for each of n consecutive days. She may buy one share on some day and sell it on a strictly later day (at most one trade). She wants the maximum profit she could have made, or 0 if no profitable trade existed.

## Problem Statement
Given the daily prices, print the maximum value of price[j] − price[i] over all pairs i < j. If that maximum is negative (prices only fall) or n = 1, print 0 (no trade is made). Do not use built-in max or min.

## Input Format
- Line 1: integer n.
- Line 2: n integers, the daily closing prices.

## Output Format
- Print one integer: the maximum profit (0 if none).

## Constraints
- 1 ≤ n ≤ 10^5
- 1 ≤ price ≤ 10^9

## Sample Input
```
8
120 98 105 90 112 130 95 118
```

## Sample Output
```
40
```
