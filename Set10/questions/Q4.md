# Set 10 - Question 4: Zero-Balance Triplets

**Difficulty:** Medium (26 marks)

## Scenario
An auditor has a list of n ledger adjustments (positive for credits, negative for debits). She suspects fraud when three adjustments cancel exactly. She wants every distinct combination of three adjustments, taken from three different positions, that adds up to zero, without listing the same combination of values twice.

## Problem Statement
Given n integers, print all distinct triplets (x, y, z) with x ≤ y ≤ z and x + y + z = 0, where the three values come from three different positions. Triplets are distinct as value combinations (for example -1 0 1 is listed once even if -1 occurs twice). Print the triplets in lexicographic order, one per line as 'x y z'; if there are none print None. Use your own sort.

## Input Format
- Line 1: integer n.
- Line 2: n integers.

## Output Format
- One triplet per line in lexicographic order, or None.

## Constraints
- 3 ≤ n ≤ 3000
- -10^5 ≤ value ≤ 10^5

## Sample Input
```
8
-1 0 1 2 -1 -4 3 -2
```

## Sample Output
```
-4 1 3
-2 -1 3
-2 0 2
-1 -1 2
-1 0 1
```
