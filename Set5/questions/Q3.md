# Set 05 - Question 3: Nearly Sorted Event Log

**Difficulty:** Easy (16 marks)

## Scenario
A server writes event timestamps almost in order, but network delays make a few events arrive late. Before storing the log, the system repairs the order with insertion sort and records how much repair work (element shifts) was needed as a measure of the delay problem.

## Problem Statement
Sort the n timestamps in non-decreasing order using insertion sort (take each element and move it left past every strictly greater element). Print the sorted list and the total number of single-position shifts performed, where moving one element one place to the right counts as one shift. Built-in sorting is not allowed.

## Input Format
- Line 1: integer n.
- Line 2: n space-separated integers, the timestamps.

## Output Format
- Line 1: the sorted timestamps.
- Line 2: the total number of shifts.

## Constraints
- 1 ≤ n ≤ 5000
- 0 ≤ timestamp ≤ 10^6

## Sample Input
```
8
10 20 15 30 40 35 50 45
```

## Sample Output
```
10 15 20 30 35 40 45 50
3
```
