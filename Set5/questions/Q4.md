# Set 05 - Question 4: Leaderboard Disorder Count

**Difficulty:** Medium (26 marks)

## Scenario
A game server lists players' scores in the order the players finished their matches. A perfectly 'fair' queue would have scores in non-decreasing order. To measure unfairness, the analyst counts the number of pairs of players where the earlier finisher has a strictly higher score than the later finisher.

## Problem Statement
Given n scores in finishing order, count the pairs of positions (i, j) with i < j and score[i] > score[j]. Print the count. Equal scores do not form an inversion. Built-in sorting is not allowed. The answer can be large, so an O(n²) pair check will not be fast enough for the largest inputs.

## Input Format
- Line 1: integer n.
- Line 2: n space-separated integers, the scores.

## Output Format
- Print one integer: the number of inversions.

## Constraints
- 1 ≤ n ≤ 10^5
- 0 ≤ score ≤ 10^9

## Sample Input
```
6
5 3 8 6 2 7
```

## Sample Output
```
7
```
