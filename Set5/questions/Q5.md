# Set 05 - Question 5: K-th Highest Salary

**Difficulty:** Medium (26 marks)

## Scenario
An HR analyst has the monthly salaries of n employees (many people share salaries) and needs the k-th highest salary, counting duplicates as separate people, for a benefits-eligibility cut-off. Sorting everyone just to read one value is wasteful.

## Problem Statement
Given n salaries and an integer k, print the k-th largest element of the multiset: the value that would be at position k if the salaries were arranged in non-increasing order (k = 1 is the maximum). Duplicates count separately. Built-in sorting is not allowed; use partitioning.

## Input Format
- Line 1: integers n and k.
- Line 2: n space-separated integers, the salaries.

## Output Format
- Print one integer: the k-th largest salary.

## Constraints
- 1 ≤ k ≤ n ≤ 10^5
- 1 ≤ salary ≤ 10^9

## Sample Input
```
9 3
40 25 60 25 90 75 60 30 50
```

## Sample Output
```
60
```
