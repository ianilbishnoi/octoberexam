# Set 05 - Question 1: Mock Test Ranking Passes

**Difficulty:** Easy (16 marks)

## Scenario
After a mock test, a teacher sorts the n marks of a small group in ascending order by hand using the 'bubble' method: she repeatedly walks along the list, swapping any two neighbouring marks that are in the wrong order. She wants to know how many walks (passes) were actually needed, meaning passes in which at least one swap happened, to judge how disordered the list was.

## Problem Statement
Implement bubble sort on the n marks (ascending). In each pass compare neighbouring pairs from the left end; swap a pair only if the left mark is strictly greater than the right one. Print the sorted marks on the first line and, on the second line, the number of productive passes, i.e. passes in which at least one swap was performed. Built-in sorting is not allowed.

## Input Format
- Line 1: integer n.
- Line 2: n space-separated integers, the marks.

## Output Format
- Line 1: the sorted marks separated by spaces.
- Line 2: the number of passes that performed at least one swap.

## Constraints
- 1 ≤ n ≤ 2000
- 0 ≤ mark ≤ 100

## Sample Input
```
5
5 1 4 2 8
```

## Sample Output
```
1 2 4 5 8
2
```
